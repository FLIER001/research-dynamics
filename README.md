# 日报项目目录说明

- 规则入口：`AGENTS.md` 管站点配置与出刊机制；四个栏目的内容规则分别在 `spec-news-brief.md`、`spec-daily-research.md`、`spec-policy-watch.md`、`spec-academic-frontier.md`。
- 常驻文件：`style-template.html`（版式模板）、`build_index.py`（首页与归档生成）、`_site_style.txt`（样式与各栏目主色源）、`index.html`（首页本地副本）、`package.json` 与 `node_modules/`（PDF 解析工具，勿删）。
- `归档/脚本/`：有代表性的生成脚本，供复刻结构时参考；一次性脚本不留在根目录。
- 成品页与过程文件的存放、清理按 `AGENTS.md` 的「文件纪律」。
